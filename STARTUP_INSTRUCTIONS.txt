TERMINAL 1: Start MySQL Server

  1. Click Windows Start menu
  2. Search for "Laragon"
  3. Open Laragon application

  2. Search for "XAMPP Control Panel"
  3. Click "Start" next to MySQL and Apache

  (or appropriate service name)

    py -c "import mysql.connector; mysql.connector.connect(host='127.0.0.1', user='root', password=''); print('MySQL OK')"

═══════════════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

PROBLEM: MySQL connection error on Python startup
SOLUTION:
  1. Verify MySQL is running in Laragon/XAMPP
  2. Check connection: 
     py -c "import mysql.connector; mysql.connector.connect(host='127.0.0.1', user='root', password='')"
  3. Verify no firewall blocking port 3306
  4. Ensure MySQL password is empty (default: root / no password)

PROBLEM: Port 5000 already in use
SOLUTION:
  Find process using port 5000:
    netstat -ano | findstr :5000
  Kill the process:
    taskkill /PID <PID> /F
  Then restart Python AI service

PROBLEM: Database tables not created
SOLUTION:
  The tables auto-create on first request to backend
  Make sure Flask is running and backend tries to connect
  Check console for error messages

PROBLEM: Frontend won't load
SOLUTION:
  1. Verify frontend file exists:
     C:\Users\PC\OneDrive\Desktop\capsatone2\frontend\index.html
  2. Check backend is running (Terminal 3)
  3. Clear browser cache (Ctrl+Shift+Del)
  4. Try different URL:
     - http://localhost:8000/../frontend/
     - or direct file path: C:\Users\PC\OneDrive\Desktop\capsatone2\frontend\index.html

PROBLEM: Chrome extension not appearing
SOLUTION:
  1. Go to chrome://extensions/
  2. Enable "Developer mode" (top-right toggle)
  3. Click "Load unpacked"
  4. Select: C:\Users\PC\OneDrive\Desktop\capsatone2\chrome_extension
  5. Check manifest.json is valid JSON
